Go + Inertia.js v3

React pages straight from Go handlers, with no API in between.

tug is a web framework for Go apps whose frontend is Inertia.js. Handlers render React, Vue or Svelte pages with typed props, and the whole app ships as one binary.

Get started{{template "i-arrow"}} Read the guide

How it fits together

A Go struct is the page's props, and its types.

A handler renders a page with a struct, which the page's component gets as its props. tug gen writes the struct's TypeScript, so the component is checked against the Go, and tug dev writes it again as the Go changes.

What's in it

The parts an app needs, already working with Inertia.

Sessions, flash messages, validation errors and CSRF work with Inertia without setup, on the standard library underneath.

  • {{template "i-page"}}

    Inertia v3, whole

    Deferred, merged, once and optional props, partial reloads by path, infinite scroll, and a page's title and description from Go.

  • {{template "i-braces"}}

    Types from Go

    tug gen writes the TypeScript of each page's props, the named routes, what each form sends and the flash data's keys.

  • {{template "i-form"}}

    Forms that check themselves

    c.BindValid binds a request and checks it by its struct tags. A form that doesn't validate goes back with its errors, and each field is checked as it's left.

  • {{template "i-key"}}

    Accounts, from one flag

    tug new -auth: registering, verified email, two-factor codes, passkeys, API tokens and notifications, in SQLite, Postgres or MySQL.

  • {{template "i-clock"}}

    Background jobs

    Jobs that run again when they fail, on a schedule in any time zone, once however often they're pushed, and in the app's own transaction.

  • {{template "i-box"}}

    One binary

    tug build makes one static binary with the frontend in it, sent gzipped by the app itself, and the app comes with a Dockerfile.

  • {{template "i-server"}}

    Rendered on the server, if you like

    tug new -ssr renders a first visit's page with Inertia's own SSR, in Node beside the app. Without Node, pages render in the browser.

  • {{template "i-check"}}

    Tests without a browser

    Package tugtest is Inertia's client for Go's tests: visits, forms, uploads and logins, with a page's props read into its Go struct.

  • {{template "i-waves"}}

    Events on every instance

    Package broadcast carries events on channels through the app's database, to the pages open on every instance, which reload what changed.
