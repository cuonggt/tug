# tug ガイド

tug は、フロントエンドに [Inertia.js](https://inertiajs.com) を使う Go アプリのための Web フレームワークです。Go のハンドラーが、間に API を挟まずに、props を渡して React、Vue、Svelte のページをレンダリングし、アプリ全体は単一のバイナリになります。このガイドでは、新しいアプリを作るところからデプロイまでを扱います。さらに詳しいことは、[pkg.go.dev](https://pkg.go.dev/github.com/cuonggt/tug) にある各パッケージのドキュメントを参照してください。

1. [はじめに](getting-started.md)：tug をインストールし、アプリを作って実行し、ページとフォームを追加します。
2. [ルーティングとハンドラー](../routing.md)：App、ルート、絶対 URL と署名付きリンク、グループ、ミドルウェア（セキュリティヘッダーもその 1 つ）、リクエストに応答したルート、プロキシの背後にいるクライアントのアドレス、`Ctx`、ファイル、ダウンロード、ストリームとイベント、リクエストのバインド、エラー。
3. [ページ](../pages.md)：Inertia のページとその props、ルートテンプレートとその nonce、後から計算される props、共有 props、リダイレクト、ページでのダウンロードとイベント、エラーページ、Vite、Inertia の DevTools。
4. [サーバーサイドレンダリング](../ssr.md)：初回訪問のページを、アプリと並んで動く Node がサーバーでレンダリングする仕組みと、`ssr` パッケージ。
5. [フォームとセッション](../forms.md)：バリデーション、アプリ独自のルール、フォーカスが外れた時点で各フィールドを検証するフォーム、フラッシュメッセージ、セッション、CSRF。
6. [多言語対応](../languages.md)：tug とアプリの文言を言語ごとのファイルから読み、リクエストの言語で表示する仕組み、`lang` パッケージ、`tug lang`。
7. [ファイル](../files.md)：サイズと種類で検証されるアップロード、`storage` パッケージによるアプリのディスクや S3 への保存、公開または署名付きのファイルへのリンク。
8. [アカウント](../auth.md)：SQLite、Postgres、MySQL で動く認証スターターと、その API トークンと通知。`auth` パッケージと、CC や BCC、添付ファイル、ワンクリックの配信停止リンクに対応した `mail` パッケージ。
9. [マイグレーション](../migrations.md)：SQL ファイルによるデータベースのテーブルの作成と変更。各ファイルは、アプリの起動時か `migrate` コマンドで、順番に 1 回ずつ実行されます。次のファイルを作る `tug migrate new` と、`migrate` パッケージ。
10. [認可](../authorization.md)：ユーザーがある対象に対して何をしてよいか、`auth` パッケージのアビリティ、理由を伝える 403 としての拒否、ページのユーザーにできることを props で渡す方法。
11. [暗号化](../encryption.md)：アプリのキー、tug がそのキーで暗号化・署名するもの、アプリ独自の値のための `crypt` パッケージ、キーのローテーション。
12. [バックグラウンドジョブ](../jobs.md)：リクエストより長くかかる処理のための `queue` パッケージ。失敗したときの再実行、スケジュールによる実行（タイムゾーンの指定も可能）、何度投入されても 1 つしか待機しないジョブ、すべてのインスタンスを通じた同時実行数や 1 秒あたりの実行数の制限、最終的な失敗と各実行の結果の通知。
13. [キャッシュ](../cache.md)：計算に時間のかかるものを、アプリのどのインスタンスからも見つけられる場所に保存する `cache` パッケージと、同時に二重に実行してはならない処理のためのロック。
14. [ブロードキャスト](../broadcasting.md)：チャンネル上のイベントを扱う `broadcast` パッケージ。イベントはアプリのデータベースを通じて、すべてのインスタンスで開かれているページに届き、ページは変わったものを再読み込みします。
15. [TypeScript](../typescript.md)：`tug gen` が Go のコードから書き出す型。
16. [テスト](../testing.md)：アプリのページ、フォーム、アップロード、ログインを Go でテストするための Inertia のクライアントである `tugtest` パッケージ、メールのための `mailtest`、イベントのテスト。
17. [デプロイ](../deployment.md)：バイナリ 1 つ、Dockerfile、環境変数、ブラウザーがアプリのページで何をしてよいかを伝えるヘッダー（Content-Security-Policy もその 1 つ）、ログ、メトリクス。
18. [CLI](../cli.md)：`tug new`、`tug dev`、`tug gen`、`tug lang`、`tug migrate`、`tug build`、`tug key` の詳細。

[ロードマップ](../roadmap.md)には、tug がどのように作られてきたか、その背後にある判断、今後の予定があります。[ベンチマーク](../benchmarks.md)には、tug がリクエストごとにかけるコスト、tug で作ったアプリの実行に必要なもの、それらの計測方法があります。
